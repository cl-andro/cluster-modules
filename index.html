Register Your Module

Cluster packages are indexed serverlessly using Git Pull Requests to maintain transparency and security.

1

Format Your Folder

Verify your module has a `package.cl` manifest and files inside `src/`. See the Contribution Guide.

2

Run Register Command

Inside your package directory, run the registry publish utility:

cl-pkg publish
This automatically appends your package config to `index.json`.
3

Submit a Pull Request

Open a Pull Request on the cluster-modules repository. Once merged, it instantly goes live!
